
A modern, visually rich portfolio website with immersive animated backgrounds and a clean, responsive experience expressing my Portfolio.

## Overview

This project is designed to showcase a stylish personal web presence with elegant motion, layered visuals, and a polished UI. It focuses on creating a memorable first impression while staying performant and responsive across devices.

## Features

- Animated and visually engaging background effects
- Responsive layout for desktop and mobile
- Clean, modern user interface
- Easy to customize and extend
- Built for a smooth browsing experience

## Tech Stack

- **Framework:** TanStack Start
- **Language:** TypeScript
- **Styling:** CSS
- **Build Tool:** Vite
- **Package Manager:** npm
